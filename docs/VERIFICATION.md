# 验证记录

验证日期：2026-09-09。项目使用 Three.js 0.180.0、Vite 6.4.3；生产构建使用本机附带的 Node.js 24.19.0。

## 结果

| 检查 | 结果 |
| --- | --- |
| `npm run verify` | 通过 |
| 生产构建 | 通过；Three.js 核心块约 503 KB，存在 Vite 默认的体积提示，无构建错误 |
| 构建后浏览器交互 | 14 项通过，无脚本异常 |
| 实际 WebGL 像素、动画与布局 | 23 项通过 |
| 绘灵法师地面范围与重置 | 通过 |
| 不同工作目录启动静态预览 | 通过 |

职业验证覆盖三个插件的资源生成/消耗、技能阶段转换、公共/独立复唱与充能、咏唱中断、目标失效、输入队列、范围衰减、身位、持续伤害、治疗/护盾、位移事件和状态到期。

浏览器实际操作覆盖移动中断、白魔法师触发技能、治疗压力与恢复、技能书、传送取消、钐镰客三连、地狱门返回、NPC 射线选择、动态怪物注册与选择、手机布局。

两个场景分别采样 81 个 WebGL 像素点，均有超过 60 种有效颜色；场景时钟持续推进。质量切换后阴影贴图实际在 768 与 1536 间切换。

布局检查使用六种视口，分别对三个职业验证技能栏、量谱和顶栏：1920×1080、1440×900、1024×768、390×844、360×740、844×390。

星空范围内实测 1.5 秒魔法缩短到 1.125 秒；移出范围后恢复 1.5 秒且不消耗超绝想象层数。重置后场地和日志清空；海都水面禁止通行，可见甲板仍可行走。

## 本地证据

- `scripts/verify.mjs`：可重复执行的职业规则验证。
- `work/interaction-check.json`：构建后实际交互记录。
- `work/render-check.json`：构建后像素、质量和多视口记录。
- `work/field-check.json`：场地效果和导航检查。

这些检查证明本训练器的上述行为可运行，不代表已与真实 7.0 客户端进行逐帧一致性验证。场景为原创程序化模型；战斗近似与未确认项明确列于 [RULES.md](RULES.md)。
